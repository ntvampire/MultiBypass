## 🌟 Основные функциональные модули

### 1. Обход DPI (Десинхронизация TCP/TLS)
- Низкоуровневая десинхронизация пакетов на базе нативного движка ByeByeDPI (`ciadpi`): нарезка TLS-записей (`--tlsrec 1+s`), изменение порядка следования сегментов (`--disorder 1`), подделка SNI (`--fake-sni google.com`) и защита от глубокого сигнатурного анализа DPI.
- **Мгновенный сброс UDP 443 (QUIC/HTTP3)**: предотвращает зависание мобильных видеоклиентов YouTube на 4-секундных таймаутах блокировок UDP и форсирует моментальное переключение на защищенный TCP/TLS-канал.
- **Автоподбор стратегий (Benchmark)**: встроенный циклический замер задержки (RTT, latency в мс) к контрольным мобильным узлам (интерфейс YouTube, потоковые серверы Googlevideo, Instagram) и применение наиболее эффективного пресета в один клик.
- Точечная фильтрация: десинхронизация применяется строго к проблемным доменам, отечественные сервисы передаются прозрачно без искажения пакетов.

### 2. Обход Telegram (Автономный WS-прокси)
- Автономный локальный демон MTProto-прокси на порту `127.0.0.1:1443` (`libtgwsproxy.so` на Rust) с инкапсуляцией трафика в WebSocket over TLS через глобальную сеть CDN Cloudflare (`/apiws`).
- Полная независимость: работает локально на устройстве независимо от системного VPN-туннеля (Telegram не требует включения в список раздельного туннелирования).
- Управление в один клик: удобная плитка в шторке быстрых настроек Android (Quick Settings Tile) и прямое открытие параметров прокси в установленном клиенте Telegram (официальный, AyuGram, Nekogram, Plus и др.) без лишнего копирования в буфер обмена.

### 3. Обход геоблока (SmartHosts & DNS-релей)
- Локальная прозрачная маршрутизация (0 мс) зарубежных сервисов с санкционными ограничениями (ChatGPT, Claude, Gemini, Adobe, Canva и др.) на проверенные европейские SNI-шлюзы.
- **Автоматизированный серверный пайплайн**: база хостов ежедневно загружается в репозиторий через GitHub Actions, очищается от несовместимых адресов (4PDA, Google Sign-In `apis.google.com`, поисковые подсказки `suggestqueries.google.com`, ресурсы зоны `.ru`/`.by`) и централизованно раздается с GitHub Pages (`ntvampire.github.io/MultiBypass`).
- **Тройное резервирование**: клиент загружает обновления списков с GitHub Pages с автоматическим резервным переходом на raw-репозиторий и апстрим при сетевых сбоях.
- Все остальные DNS-запросы направляются напрямую в нативный DNS оператора связи через защищенный сокет (`protect()`), сохраняя максимальную скорость и совместимость с банковскими клиентами и государственными порталами.

### 4. Бесшовный хэндовер сетей (Wi-Fi ↔ Мобильная сеть)
- Мониторинг сетевых интерфейсов на уровне `NetworkCallback`: при переключении между Wi-Fi и сотовой сетью стек мгновенно сбрасывает зависшие сокеты и обновляет сетевые маршруты без прерывания пользовательских сессий.

### 5. Сетевой доктор и диагностика
- Экспресс-проверка сетевого окружения в один клик: замер пинга, проверка доступности локальных шлюзов и качества десинхронизации TCP.

### 6. Избирательная маршрутизация (Split-Tunneling)
- Возможность выбора конкретных приложений устройства для изоляции в защищенном туннеле (`addAllowedApplication`). Невыбранные программы работают напрямую через физическую сеть оператора без накладных расходов.

## 📥 Загрузка (Сборки APK)

Готовые скомпилированные и подписанные пакеты актуальной версии всегда доступны на странице последнего опубликованного релиза:  
👉 **[Скачать последнюю версию MultiBypass на GitHub Releases](https://github.com/ntvampire/MultiBypass/releases/latest)**

Доступные установочные пакеты:
- **`MultiBypass-*-arm64-v8a.apk`** — 64-битная архитектура ARM (рекомендуется для подавляющего большинства современных смартфонов и планшетов на Android 9+).
- **`MultiBypass-*-universal.apk`** — универсальный пакет, содержащий нативные библиотеки для всех поддерживаемых архитектур (подходит для любых устройств, включая эмуляторы).
- **`MultiBypass-*-armeabi-v7a.apk`** — 32-битная архитектура ARM для более ранних моделей устройств.

## 💖 Сторонние компоненты и благодарности (Credits & Attribution)

Проект **MultiBypass** разработан с интеграцией наработок независимых открытых проектов:

- **[ByeByeDPI (ciadpi)](https://github.com/hufrea/byedpi)** (автор: [@hufrea](https://github.com/hufrea), форки: [@romanvht](https://github.com/romanvht), [@ValdikSS](https://github.com/ValdikSS))  
  Низкоуровневая реализация на C для управления фрагментацией TCP-пакетов, манипуляций с заголовками TLS ClientHello и генерации OOB-данных (`libbyedpi.so`).

- **[hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel)** (автор: [@heiher](https://github.com/heiher))  
  Высокопроизводительный транслятор виртуального интерфейса TUN в протокол SOCKS5 (`libhev-socks5-tunnel.so`).

- **[tg-ws-proxy](https://github.com/Flowseal/zapret-discord-youtube)** / **[tg-ws-proxy-android](https://github.com/amurcanov/tg-ws-proxy-android)** (авторы: Flowseal, amurcanov, coyove)  
  Высокопроизводительный нативный демон инкапсуляции трафика MTProto в WebSocket over TLS (`libtgwsproxy.so`).

- **[RussiaFancyLists](https://github.com/Noktomezo/RussiaFancyLists)** (автор: [@Noktomezo](https://github.com/Noktomezo))  
  База соответствий доменов и адресов (`smart-no-crutch`) для локальной маршрутизации и обхода геоблоков.

- **[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)** (автор: [@Flowseal](https://github.com/Flowseal))  
  Базовые списки доменов и узлов для обхода замедлений и фильтрации DPI.

- **[OkHttp & okhttp-dnsoverhttps](https://github.com/square/okhttp)** (Square)  
  Сетевой стек для работы с HTTP-клиентами и DNS-over-HTTPS (RFC 8484).

- **[Jetpack Compose](https://developer.android.com/jetpack/compose)** (Google)
