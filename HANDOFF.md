# Сводка проекта MultiBypass (Актуально для v3.0.0+)

## 1. Назначение и Архитектура

**MultiBypass** — специализированная утилита раздельной маршрутизации, десинхронизации TCP и обхода сетевых ограничений для Android (API 28–34+), построенная по архитектуре роутеров Keenetic / OpenWrt:

- **Ядро перехвата**: `hev-socks5-tunnel` v2.19.1 транслирует IP-трафик с виртуального TUN-интерфейса в локальный сетевой диспетчер.
- **SOCKS5-диспетчер**: локальный асинхронный маршрутизатор трафика (порт `10800`), распределяющий потоки:
  1. **SmartHosts**: встроенный перехват DNS-запросов (порт 53) с локальным резолвингом зарубежных сервисов (ChatGPT, Gemini, Claude, Spotify, Canva и др.) на проверенные европейские SNI-релеи по списку `smart-no-crutch.hosts` (проект *RussiaFancyLists*). Запросы 4PDA направляются напрямую в DNS оператора.
  2. **ByeByeDPI**: модифицированный нативный C-движок `proxy.c` (порт `1080`) для обхода замедлений и ТСПУ в РФ (YouTube, Discord, Meta, X/Twitter).
  3. **Прямой интернет**: незаблокированные ресурсы, российские сервисы и белые списки оператора работают напрямую без замедлений и прокси.
- **Обход Telegram (локальный MTProto WS Proxy)**:
  - Работает через `libtgwsproxy.so` (Rust) на локальном порту `127.0.0.1:1443`.
  - Запускается и останавливается полностью независимо от основного VPN-туннеля через `TelegramProxyService` (FGS) или шторку быстрых настроек (`TelegramProxyTileService`).
  - Подключение клиента Telegram выполняется в 1 клик по ссылке `tg://proxy?server=127.0.0.1&port=1443&secret=...`.
  - Telegram подключается по локальному loopback (`127.0.0.1`), минуя TUN-интерфейс VPN. Приложению Telegram не требуется выбор в списке раздельной маршрутизации.
- **Изоляция сетей и Хэндовер**:
  - Исключение приватных сетей (`Bypass LAN` по умолчанию) через `builder.excludeRoute()`.
  - Динамическая миграция при смене Wi-Fi ↔ LTE: автоматический сброс зависших сокетов в `Socks5Dispatcher` и обновление DNS оператора.
- **Автообновление**: системный `PackageInstaller.Session` с автоматической фоновой установкой APK.
- **Автоподбор стратегий**: тестирование стратегий TCP десинхронизации с сохранением результатов и применением в 1 клик.

## 2. Текущее состояние

- **Репозиторий**: `d:\Projects\MultiBypass`
- **Ветка**: `main`.
- **Сборка**: `assembleRelease` генерирует 3 подписанных APK (`arm64-v8a`, `armeabi-v7a`, `universal`).

### Ключевые компоненты Telegram Proxy:
- `TelegramProxyService.kt`: автономный сервис для локального MTProto прокси.
- `TelegramProxyTileService.kt`: плитка в шторке быстрых настроек (Quick Settings Tile).
- `NativeTgProxy.kt`: JNA интерфейс к `libtgwsproxy.so` с пулом адресов Cloudflare.
- `MainScreen.kt`: карточка с независимым тумблером и кнопкой «Подключить в Telegram (1 клик)».
