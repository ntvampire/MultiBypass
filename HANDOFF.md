# Сводка проекта MultiBypass (Актуально для v2.1.1)

## 1. Назначение и Архитектура

**MultiBypass** — специализированная утилита раздельной маршрутизации, десинхронизации TCP и обхода сетевых ограничений для Android (API 28–34+), построенная по архитектуре роутеров Keenetic / OpenWrt:

- **Ядро перехвата**: `hev-socks5-tunnel` v2.19.1 транслирует IP-трафик с виртуального TUN-интерфейса в локальный сетевой диспетчер.
- **SOCKS5-диспетчер**: локальный асинхронный маршрутизатор трафика (порт `10800`), распределяющий потоки между компонентами:
  1. **SmartHosts**: встроенный перехват DNS-запросов (порт 53) с локальным резолвингом зарубежных сервисов (ChatGPT, Gemini, Claude, Spotify, Canva и др.) на проверенные европейские SNI-релеи по списку `smart-no-crutch.hosts` (проект *RussiaFancyLists*). Исключение для 4PDA направляет запросы в DNS оператора.
  2. **Telegram sTGWS**: прямое прозрачное туннелирование трафика дата-центров Telegram (AS44907, AS62041) в защищённые WebSocket-шлюзы Cloudflare без необходимости ручной настройки прокси в Telegram.
  3. **ByeByeDPI**: модифицированный нативный C-движок `proxy.c` (порт `1080`) для обхода замедлений и ТСПУ в РФ (YouTube, Discord, Meta, X/Twitter).
  4. **Прямой интернет**: незаблокированные ресурсы, российские сервисы и белые списки оператора работают напрямую без замедлений и прокси.
- **Изоляция сетей**:
  - Исключение приватных сетей (`Bypass LAN` по умолчанию) через `builder.excludeRoute()`.
  - Маршрутизация приложений: по умолчанию для движка обхода включены все приложения с возможностью гибкого выбора в диалоге («Выбрать все / Снять все»).
- **Автообновление**: системный `PackageInstaller.Session` с автоматической фоновой установкой APK.
- **Автоподбор стратегий**: фоновое тестирование с `PowerManager.WakeLock` и сохранением результатов последней проверки с применением в 1 клик.
- **База стратегий**: пресеты десинхронизации структурированы от простых к сложным (сплиты/дисордеры -> фейковые пакеты/TTL -> TLS-Record splitting/Fake SNI -> многоступенчатые фильтры).

## 2. Текущее состояние (Версия v2.1.1)

- **Репозиторий**: `d:\Projects\MultiBypass`
- **Ветка**: `main` (полная синхронизация с `origin/main`).
- **Релизы на GitHub**: активны только версии поколения 2.x (`v2.0.0`, `v2.1.0`, `v2.1.1`).
- **Сборка**: `assembleRelease` генерирует 3 подписанных APK (`arm64-v8a`, `armeabi-v7a`, `universal`).

### История версий поколения 2.x:
- **v2.1.1**:
  - Автоматическое исключение 4PDA из SmartHosts для восстановления работы сайта и приложения 4PDA.
  - Упрощение управления маршрутизацией приложений в Настройках, кнопка «Выбрать все / Снять все».
  - Отмена сброса QUIC (UDP 443), восстановление работы приложения YouTube.
  - Сортировка стратегий от простых к сложным и надежная синхронизация обновлений.
  - Очистка устаревших карточек и описаний.
- **v2.1.0**:
  - Интеграция пула CFProxy (`cfproxy_domains.txt`) для Telegram sTGWS.
  - Расширение сетевого доктора тестами CDN и превью YouTube.
- **v2.0.0**:
  - Переход со стороннего SmartDNS на локальную базу SmartHosts (`smart-no-crutch.hosts`).
  - Устранение всех лишних экранов настройки DNS и устаревших компонентов.
