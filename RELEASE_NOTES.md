- 🤖 **Google Gemini & Google Assistant Mobile**:
  - В группу «Свой DNS» включен полный мобильный стек сервисов Google Gemini и Google Assistant (`gemini.google.com`, `generativeai.google.com`, `proactivebackend-pa.googleapis.com`, `geller-pa.googleapis.com`, `alkalimakersuite-pa.clients6.google.com`, `speech-dispatcher.clients6.google.com` и др.) для полноценной и стабильной работы голосового ассистента на смартфонах в РФ.

- 🔄 **Автоматическая актуализация списков через GitHub Actions & Pages**:
  - Настроен ежедневный фоновый пайплайн в GitHub Actions, собирающий и проверяющий домены в непиковое время (01:23 UTC).
  - Списки публикуются на GitHub Pages (`ntvampire.github.io/MultiBypass`), гарантируя надежную доставку обновлений в обход возможных блокировок `githubusercontent`.

- 🛡️ **Мобильная оптимизация и фильтрация списков**:
  - Списки доменов строго разделены по назначению: «Свой DNS / Geo-unblock» (`domains_dns.txt`) и «Десинхронизация TCP / ByeByeDPI» (`domains_antidpi.txt`).
  - Из списков полностью удален нерелевантный для смартфонов балласт (торренты, трекеры, казино), а также национальные домены (`.ru`, `.рф`, `.by`), государственные сервисы и российские банки для прямого подключения без туннелирования.

- 💾 **Сохранение пользовательских доменов**:
  - Адреса, добавленные вручную пользователем, теперь сохраняются в изолированном хранилище и гарантированно не затираются при сетевой синхронизации или нажатии кнопки «Сброс».
