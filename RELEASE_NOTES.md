### 🌟 Обновление v1.2.0:

- 📱 **Плитки в шторке быстрых настроек Android (Quick Settings Tiles)**:
  - Добавлена плитка **MultiBypass** для быстрого запуска и остановки основного VPN-сервиса в один тап без входа в приложение.
  - Добавлена независимая плитка **Telegram Proxy** для включения и выключения локального MTProto WS-шлюза автономно, без запуска основного VPN-туннеля.

- 🚀 **Автовыбор популярных приложений при первом старте (Zero-Config UX)**:
  - При первой установке приложение автоматически находит установленные на устройстве сервисы (YouTube, Instagram, Discord, Telegram, ChatGPT, Spotify, Facebook, Chrome) и включает их в список маршрутизации. Приложение готово к работе сразу после первого нажатия «Подключить».

- 🌐 **Расширенная база доменов по умолчанию**:
  - В группу «Свой DNS» добавлены сервисы Google Gemini & AI Studio, PlayStation Network, Xbox Live, аудио-CDN Spotify и SoundCloud.
  - В группу «Десинхронизация TCP» добавлены критические узлы Discord (Gateway & Voice), YouTube 4K стриминг (wide-youtube), Cloudflare ECH и Signal.

- 🛡️ **Стабилизация жизненного цикла VpnService и очистки ресурсов**:
  - Реализован строгий порядок завершения служб туннелирования: остановка перехвата пакетов `TProxyService` → выдержка буферного интервала очистки ядра → безопасное закрытие и освобождение дескриптора `tunFd` → остановка демона ByeDpi и локального DoH-сервера. Исключены утечки дескрипторов сокетов при частых переключениях.
  - Внедрена мьютекс-синхронизация (`vpnMutex`) и действие `ACTION_RECONNECT` для плавного мягкого перезапуска внутренних сокетов без сброса Vpn-интерфейса ОС.

- ⚡ **Устойчивость сетевых сокетов при миграции между сетями (Wi-Fi ↔ LTE)**:
  - Автономный сторожевой модуль `ServiceWatchdog` получил интеллектуальный дебаунс (2000 мс) на сетевые события и двухэтапную валидацию сокетов перед принятием решения о перезапуске.
  - Добавлена валидация сетевого состояния (`NET_CAPABILITY_VALIDATED`) при смене физического сетевого интерфейса.

- 🎯 **Актуализация узлов автоподбора стратегий TCP**:
  - Тестовая триада сервисов автоподбора обновлена на актуальные ресурсы: **YouTube**, **Instagram** и **Facebook**.
  - Замер задержки и доступности пакетов выполняется напрямую через изолированный SOCKS-канал.

- 🎨 **Улучшения интерфейса и быстрого доступа**:
  - На Главный экран добавлена кнопка быстрого перезапуска внутренних сетевых сокетов в один клик.
  - Модальное окно выбора приложений оптимизировано под плавную работу при большом количестве установленных пакетов.

### 🌟 Обновление v1.1.3:

- ⚙️ **Оптимизированная стратегия по умолчанию для модуля десинхронизации TCP**:
  - В качестве стратегии десинхронизации по умолчанию установлен профиль **`-o1 -r-5+se -a1`** (перемещение OOB-маркера и реверсивная фрагментация SNI). Данная конфигурация демонстрирует наивысшую устойчивость и минимальные задержки при тестировании на актуальных сетевых маршрутах.
  - Профиль перемещён на первое место в списке пресетов и алгоритмов тестирования.
  - Для существующих пользователей, использовавших стандартный профиль, обновление стратегии выполняется автоматически при первом запуске новой версии.

### 🌟 Главные нововведения ветки v1.1:

- 🎨 **Упрощение и лаконичность интерфейса**:
  - Из названий разделов и заголовков экранов настроек убрана служебная нумерация «Группа 1» и «Группа 2» — теперь используются прямые понятные названия «Свой DNS» и «Десинхронизация TCP».
  - Из раздела настроек «Стабильность и работа в фоне» убран пункт контроля служб (Watchdog) — сторожевой механизм защиты сетевых служб работает в полностью прозрачном автономном режиме без перегрузки интерфейса.

- 📱 **Единый выбор приложений для раздельной маршрутизации (Split Tunneling)**:
  - Централизованное управление маршрутизацией трафика на Главном экране приложения. Выбор исключён из настроек отдельных групп, устранено троекратное дублирование.
  - Кнопка **«Выбрать популярные»** в 1 клик для быстрого включения установленных приложений (YouTube, Instagram, Discord, Telegram, ChatGPT, X/Twitter, Chrome, Spotify, TikTok).
  - Быстрая очистка «Снять все» и закрепление выбранных приложений вверху списка.

- 🌐 **Специализированные профили DNS (Альтернативный резолвинг)**:
  - Список оптимизирован под специализированные профили: `Comss.one DNS` (по умолчанию), `Xbox / Microsoft DNS`, `DNS-AI`, `NextDNS` (с поддержкой пользовательского профиля) и `Пользовательский`.
  - Удалены стандартные неизбирательные провайдеры (Google, Яндекс, AdGuard, Quad9).

- 🛡️ **Отказоустойчивость DoH (Резервный переход на порт 53)**:
  - Прозрачный гибридный режим: при недоступности или сетевых сбоях шифрованного DoH-канала приложение бесшовно переключается на стандартный UDP-порт 53 выбранного сервиса.

- ⚡ **Стабильная фоновая загрузка обновлений (WakeLock + Уведомления)**:
  - Загрузка APK-обновлений из настроек защищена от засыпания экрана устройства и сворачивания приложения.
  - Нативное уведомление в шторке Android с прогресс-баром и автоматическим запуском установщика пакетов.

- 🔙 **Полноценная навигация кнопкой «Назад»**:
  - Аппаратная кнопка «Назад» и системные жесты возвращают на предыдущий/главный экран на всех экранах приложения без случайного закрытия программы.

- 🎯 **Улучшенный автоподбор параметров десинхронизации TCP**:
  - Автоподбор стратегий перенесён в экран настроек десинхронизации TCP и оптимизирован для тестирования на ключевых сервисах: **YouTube**, **Instagram** и **X (Twitter)**.
  - Подробные индикаторы успешных сервисов и точный замер сетевой задержки (RTT, latency).

- 🔑 **Постоянное сохранение ключа Telegram WS Proxy**:
  - Секретный ключ MTProto-прокси надёжно сохраняется в постоянной конфигурации — повторное подключение прокси в клиенте Telegram после обновлений приложения не требуется.
