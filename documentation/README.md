# Документация проекта MultiBypass

Локальная инженерная база знаний по проекту **MultiBypass** (Android 9+ / API 28–34+).

> [!NOTE]
> В корне репозитория каталог `docs/` зарезервирован под статическую раздачу списков через GitHub Pages (`domains_antidpi.txt`, `smart-no-crutch.hosts`, `strategies.txt`, `domains_version.json`). Вся проектная документация ведётся здесь, в `documentation/`.

## Структура разделов

| Файл | Назначение |
| :--- | :--- |
| [01_TZ.md](./01_TZ.md) | Техническое задание: цели, функциональные и нефункциональные требования, правила маршрутизации и изоляции. |
| [02_ARCHITECTURE.md](./02_ARCHITECTURE.md) | Архитектура сетевого конвейера, локальные порты, DNS-релей, нативные модули (`C` / `Rust`), CI/CD пайплайны. |
| [03_FEATURES.md](./03_FEATURES.md) | Реестр реализованных возможностей, привязка к компонентам кода и история ключевых вех. |
| [04_ROADMAP.md](./04_ROADMAP.md) | План развития, текущие задачи, бэклог идей и журнал технического долга. |

## Правила актуализации
1. При реализации новой фичи или изменении портов/стратегий/маршрутизации обновляются [03_FEATURES.md](./03_FEATURES.md) и статус задач в [04_ROADMAP.md](./04_ROADMAP.md).
2. При пересмотре системных потоков данных или контрактов модулей корректируются [01_TZ.md](./01_TZ.md) и [02_ARCHITECTURE.md](./02_ARCHITECTURE.md).
3. Актуальная зафиксированная версия сборки в `app/build.gradle.kts`: **`v4.0.0` (`versionCode = 51`)**.
